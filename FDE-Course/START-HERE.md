# Start here — Forward Deployed Delivery

## Open the course
Extract the entire archive before opening index.html. Choose English or Spanish. Keep its folder structure intact so videos and documents resolve. A current desktop browser can open the reader without a learning-platform account. Captions are embedded in the reader for local playback; SRT and VTT files are also supplied for uploads. Browser notes save locally when permitted. Quizzes give immediate feedback; they do not verify identity or report completion to an LMS.

## What is included
- 9 modules and 36 lessons per language, with practical tasks and worked responses.
- 72 lesson videos plus 4 bonus demonstration/introduction videos, all 1080p.
- English lesson video: 56.5 minutes. English bonuses: 2.5 minutes.
- Spanish lesson video: 52.6 minutes. Spanish bonuses: 2.3 minutes.
- 520 planned practice minutes per edition, including the coding lab and capstone. These are planning estimates. The original four-to-five-hour video estimate is superseded by these measured runtimes.
- PDFs, editable Markdown sources, 181-slide editable decks per language, quizzes, templates, capstone evidence and source mapping.
- MP3 audio, transcripts, SRT and VTT captions for every video.
- A local Docker prototype, starter exercise, sample evidence and seven meaningful test groups.
- Cover art and bilingual glossary; publisher sales and production files are excluded from this free learner edition.

## Learn
Start with M01-L01. Keep a dated portfolio. Pause at each task, write your response, then compare with the worked answer. Complete modules in order. Use the coding guide before M04 practice. Open capstone evidence in stages. The two Sense readings assess prototype evidence and subsequent adoption separately.

## Run the lab
Open lab/RUN-LOCALLY-en.md or lab/RUN-LOCALLY-es.md for clone instructions, native Python 3.14 and Docker alternatives. The original timed lab guides remain in lab/README-en.pdf and lab/README-es.pdf. Basic Python familiarity is needed; Docker is optional when Python is installed. No paid AI API or customer data is required. The prototype uses deterministic rules; AI comparison is an optional exercise.
