# Voice and artwork production
Narration was generated locally with Kokoro-82M, using af_heart for English and ef_dora for Spanish. Voices are synthetic and do not impersonate Beto. No voice recording was requested or cloned. No paid model API was used.

The original Kokoro model release identifies Apache-2.0 licensing. The kokoro-onnx runtime identifies MIT licensing. Model weights and voice files are not redistributed in this learner package. Production references and versions are recorded for traceability, without asserting exclusive rights to third-party components.

Primary references:
- https://huggingface.co/hexgrad/Kokoro-82M
- https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md
- https://github.com/thewh1teagle/kokoro-onnx

English and Spanish media use actual script and cue timings. The supplied MP4 files contain H.264 picture and AAC audio. Separate MP3, SRT, VTT and transcript files are included. Picture is 1920 by 1080. Encoding normalizes speech loudness; automatic checks do not substitute for a human listening review.

The cover is a generated fictional engineering worktable, not a customer site photograph. No customer brand, testimonial or field outcome is depicted. The editable slide decks contain native text; the course media show those instructional slides. The bonus lab demonstration shows the actual local teaching application's interface.
